# ADR-0003: 項目は 1 ソフト 1 ページとし、hugo-theme-bestiary で描く

- 状態: 採用

## 文脈

サイトは Blowfish テーマを使い、提供形態ごとの 1 ページに、複数のソフトを見出しとリンクの箇条書きで並べていた。ADR-0002 で、各項目に種別を付けることが決まった。見出しと箇条書きには、種別のような決まった欄を持たせる書式がなく、書き手ごとに書き方が揺れる。

[hugo-theme-bestiary](https://github.com/ShortArrow/hugo-theme-bestiary) は、ページの front matter の `params` にある欄を、サイトが宣言した欄の定義に従って項目カードとして描くテーマである。宣言にない選択肢を書くと、ビルドが失敗する。

## 決定

- テーマは、Hugo Module として取り込む hugo-theme-bestiary とする。
- 1 つのソフトを 1 ページとし、提供形態はセクション（`content/en/<提供形態>/`）とする。セクションのページは、そのソフトの一覧になる。
- 項目の欄は `config/_default/params.toml` で宣言する。

| 欄 | 型 | 中身 |
|---|---|---|
| Kind | 選択肢 | ADR-0002 の種別。原種 = Progenitor、寄生 = Parasite、共生 = Symbiont、擬態 = Mimic、近縁種 = Kin |
| Habitat | 文字 | そのソフトが動くアプリや環境 |
| Sightings | リンク一覧 | 公式サイト、リポジトリ、ストアなど |
| Last verified | 日付 | 書いてあることを確かめた日 |

## 理由

- 種別を選択肢として宣言するので、種別の書き間違いはビルドで止まる。
- 欄が決まっているので、項目ごとの書き方が揃う。
- 1 ソフト 1 ページなので、項目ごとに確かめた日を持てる。

## 採らなかった案

- Blowfish のまま、見出しの下に種別を書き足す：種別の書き間違いを検出できず、欄の書き方も揃わない。

## 結果

- `/browser/#firenvim` のような、ページ内の見出しへのリンクは切れる。各ソフトのページは `/browser/firenvim/` に移る。セクションのページの URL は変わらない。
- Blowfish のショートコード（`alert`、`lead`、`icon`）は使えない。
- テーマの版は `go.mod` で固定する。
